# Exercícios de C# com Windows Forms

Repositório de estudos de programação e interfaces gráficas. Reúne quatro atividades em C# com Windows Forms e .NET Framework 4.8.

## Projetos

| Pasta | Atividade | Conceitos praticados |
| --- | --- | --- |
| [Curso](Curso) | Cadastro com escolha de curso e resumo dos dados | TextBox, ListBox, RadioButton, CheckBox, validações e condicionais |
| [Imc](Imc) | Cálculo de IMC com exibição em gráfico | NumericUpDown, operações matemáticas e gráfico de colunas |
| [Cores](Cores) | Interação para trocar cores | Eventos, botões e propriedades visuais |
| [Quiz](Quiz) | Quiz com cinco perguntas e cálculo da nota | RadioButton, condicionais, validação e pontuação |

## Como executar

1. Use um computador com Windows e Visual Studio com a carga de trabalho **Desenvolvimento para desktop com .NET** e suporte ao **.NET Framework 4.8**.
2. Baixe ou clone este repositório.
3. Entre na pasta do exercício e abra o arquivo `.sln`, por exemplo `Quiz/Quiz.sln`.
4. Pressione **F5** no Visual Studio.

Cada exercício é um projeto independente. Os programas são aplicativos de desktop; o GitHub permite consultar o código e baixar os arquivos.

## Organização dos arquivos

- `.sln`: solução que você abre no Visual Studio.
- `.csproj`: configurações e referências do projeto.
- `.cs`: código C#.
- `.Designer.cs` e `.resx`: estrutura e recursos dos formulários.
